# 银河粒子风暴 v0.2 设计补充

日期：2026-08-02  
状态：依据已批准的四态银河规格与本轮“动态效果为 0”反馈执行

## 问题诊断

v0.1 的 Canvas 虽持续刷新，但粒子只在二维椭圆内缓慢旋转；状态变化主要依靠椭圆压扁和轻微提速，同时画布被两层深色前景渐变覆盖。结果是技术上存在动画，视觉上缺少可感知的位移、景深、冲击和状态差异。

## 采用方案

保持单 HTML、离线运行和零外部依赖，使用自研 3D 投影粒子场移植 FitDice 已验证的核心机制：预生成类型化数组、每帧计算目标位置、透视投影到 Canvas、按深度调整大小与亮度。

四个状态分别表现为：

- `idle`：正面可见的缓慢旋转银河盘，保持安静但明确可动。
- `reflecting`：投问触发中心冲击波，银河向侧面翻转并吸入中心。
- `branching`：多臂粒子风暴、湍流轨迹和高速能量流，表达问题路径展开。
- `ready`：风暴减速并收束为稳定星带与连线，表达阶段成果形成。

状态间使用连续插值而不是瞬间跳变。鼠标或触摸只产生轻微视差；低动态模式保留静态形态差异，停止高速旋转、冲击波和拖尾。

## 性能与降级

- 桌面上限约 1,400 粒子，移动端约 620 粒子。
- 设备像素比限制为 1.75，并在页面不可见时暂停帧循环。
- Canvas 不承载关键文字；上下文不可用时继续使用现有 CSS 星云降级层。
- 不引入 Three.js CDN，以维持单文件离线交付约束。

## 验收

- 粒子数据使用 `Float32Array`，状态采样函数可独立测试。
- `idle`、`reflecting`、`branching`、`ready` 的空间轮廓和速度参数显著不同。
- 投问操作调用一次冲击效果；分支与成果操作继续驱动状态机。
- 1440×810 与 390×844 无横向溢出；低动态开关仍有效。
