# Method library

Choose the method from the thinking bottleneck, not from novelty. Recommend one primary method and no more than two alternatives.

| Method | Use when | Avoid when | Expected output |
| --- | --- | --- | --- |
| 苏格拉底式探寻 | Key terms, evidence, assumptions, or desired outcome are unclear | The user already has a precise causal model and only needs verification | Clarified proposition, assumptions, rival explanations |
| Multi-branch `5-Why` | There is one observable phenomenon and several possible causal chains | The “why” answers would be speculation without observations | Cause tree, breakpoints, validation needs |
| 六顶思考帽 | Stakeholders are arguing from incompatible modes such as facts, risk and opportunity | One factual definition is the only bottleneck | Parallel viewpoints, conflicts, synthesis |
| 曼陀罗思考法 | The original frame is narrow and adjacent dimensions are missing | The user is already overloaded with branches | Eight dimensions, adjacent questions, opportunity map |
| A4 纸思考法 | The user needs rapid externalization of many fragments | Deep evidence review is immediately required | Time-boxed notes, repeated patterns, next actions |
| 雇佣式探寻（JTBD） | The question is framed from the supply side (features, competitors, adoption), or the user's user/team/beneficiary and their real moment matter, or the real substitute is unknown | The user already has a precise scene-level task and only needs causal verification within their own process | Hiring moment, hired job, real substitute, decision/research interface |

## Socratic sequence

Generate questions dynamically, usually in this order:

1. Definition: “你说的 X，具体用什么可观察现象判断？”
2. Evidence: “什么事实支持这个判断？什么事实可能反驳它？”
3. Attribution: “为什么更像是 A，而不是 B 或 C？”
4. Mechanism: “A 通过什么过程影响结果？”
5. Boundary: “在哪些团队、阶段或条件下不成立？”
6. Decision: “如果判断成立，你下一步会改变什么？”

Ask only the question that unlocks the largest uncertainty now.

## Multi-branch 5-Why

Never force one linear root cause. From the observed phenomenon, create two or three candidate causes. Pursue each until reaching an actionable mechanism, a controllable condition, or an evidence gap. Stop when the next “why” would only produce unsupported speculation.

## Six hats

Use hats as lenses, not personas:

- white: known facts and missing data;
- red: intuition and felt stakes, without justification pressure;
- black: risks and failure modes;
- yellow: value and opportunity;
- green: alternatives and experiments;
- blue: synthesis, decision rule and next step.

## 雇佣式探寻（JTBD）三问

当问题停留在供给方视角（功能、竞品、要不要投入）或涉及你的用户/团队/受益者的真实使用时刻时，用这三个问题把视角从"我"换到"他/他们"，逐步找到真正被雇佣的任务与真实对手。逐问，一次只问信息价值最高的一问，不要倾倒问卷：

1. **他们会在什么时刻想起我？**——定位雇佣时刻与使用场景（when / where / who）。
2. **那一刻，他们想完成什么？**——识别被雇佣的任务与动机（job），而不是"产品有什么功能"。
3. **如果没有我，他们会怎么办？**——找到真实替代方案（substitute），也就是你真正的竞争对手。

产出映射到问题簇既有节点类型：雇佣时刻/场景 → `boundary`；被雇佣的任务/动机 → `cause`/`mechanism`；真实替代/对手 → `rival`；尚不可见或未满足的任务 → `evidence-gap`/`decision`。追问遵循 Socratic sequence 的"Ask only the question that unlocks the largest uncertainty now"。

## Research-question readiness

Move to forging only when the inquiry has: an observable phenomenon, at least one candidate mechanism, a plausible outcome, a unit/context, and named evidence gaps. Otherwise continue exploration or produce a decision hypothesis card.
