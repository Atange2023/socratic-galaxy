使用说明

这不是答案机器，
而是一张思考地图。

  1. 投问写下真实困惑，不必先修饰。
  2. 展开从四个方向选择最有感觉的一条。
  3. 产出把阶段性思考做成可编辑成果。
  4. 带走下载 Markdown 或 JSON，继续在 Obsidian 使用。

系统不会根据措辞诊断情绪或人格。你的状态只来自主动选择，且仅保存在本机。
